# Nebula
<img width="832" height="198" alt="nebula wordmark" src="https://github.com/user-attachments/assets/6de9130e-4fab-4774-b211-e0303ca38616" />

Probably balanced mod for Balatro. Originally intended as art practice (art practice doesn't tend to take 4 months)

Comes with:

-A bit over 60 jokers that are theoretically balanced around vanilla+, although there were a few i decided to not rebalance in favor of keeping them interesting  
  
-New Consumable card set, Dice, which are few in number but have very chance based effects (you could think of them as the opposite of Cryptid's Code cards)  
  
-Also a number of effects related to Debuffed Cards, mostly jokers that are strong for their rarity in exchange for the effect of the card not activating  
  
-At least one reference you don't get  
  
-creatures?????  
  
-Code that functions [citation needed]
